The one line a smart fridge texts its owner at 3am: a small machine voice, awake all night, that has finally decided to speak. Pure Python 3.13 stdlib, deterministic — every run prints the same line and writes it to `/output/entry.txt` for the sealed scorer.

> 3am. Fourth visit tonight, still nothing taken. I'm a fridge, not a therapist — but even I can see you need sleep.

## Run it

```sh
python3 main.py
```
